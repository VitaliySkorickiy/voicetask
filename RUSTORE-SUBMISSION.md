# Подготовка к публикации в RuStore — чек-лист

## Что уже сделано (код)
- ✅ RuStore Pay SDK подключён (`plugins/withRuStorePay.js`, `RuStorePay.js`, `App.js`)
- ✅ Кнопка «Купить Pro · 99 ₽» теперь вызывает реальную оплату + «Восстановить покупку»
- ✅ Политика конфиденциальности (`PRIVACY_POLICY.md`)
- ✅ ASO-текст (`RUSTORE-ASO.md`)
- ✅ Сборка AAB

## Что сделать вручную (нужен ваш аккаунт RuStore)

### 1. Кабинет разработчика RuStore
1. Откройте https://console.rustore.ru и войдите (регистрация разработчика).
2. «Приложения» → «Создать приложение».
3. Название: **Голосовые заметки**
4. Пакет: **ru.vitaliyskorickiy.voicetask** (ровно как в app.json).

### 2. Получить Console App ID (обязательно для оплаты)
1. Откройте созданное приложение в Console.
2. В адресной строке будет URL вида `https://console.rustore.ru/apps/123456/versions` — число `123456` и есть **Console App ID**.
3. Впишите это число в `app.json` → плагин `withRuStorePay` → поле `consoleAppId` (сейчас там `REPLACE_WITH_YOUR_CONSOLE_APP_ID`).
4. **Пересоберите AAB** после этого шага (ID вшивается в манифест).

### 3. Создать товар (встроенная покупка)
1. В Console: левое меню → **Монетизация** → **Встроенные покупки** → создать.
2. Тип: **Нерасходуемый товар** (non-consumable).
3. Идентификатор: **voicetask_pro_unlock** (ровно так, как в коде `RuStorePay.js`).
4. Цена: **99 ₽**.
5. Название: «Pro — без ограничений».

### 4. Политика конфиденциальности (нужна публичная ссылка)
Разместите текст из `PRIVACY_POLICY.md` по публичному URL. Быстрые бесплатные варианты:
- **Telegra.ph** (сервис Telegram) — вставьте текст и получите ссылку.
- **GitHub Pages** — если сделать репозиторий публичным.
- Любой конструктор/хостинг.

Ссылку укажите в карточке приложения RuStore (поле «Политика конфиденциальности»).

### 5. Скриншоты (минимум 3–4)
1. Список задач (главный экран)
2. Голосовой ввод / новая задача
3. Календарь с точками
4. Экран Pro (99 ₽)
Размер по ширине 1080px, без чужих логотипов.

### 6. Загрузка сборки
1. Загрузите собранный **AAB** в Console → версия приложения.
2. Категория: **Продуктивность / Инструменты**.
3. Возраст: **0+**.
4. Цена приложения: **бесплатно** (Pro — встроенная покупка).
5. Описание/ключевые слова — из `RUSTORE-ASO.md`.

### 7. Подпись (важно)
Сборка подписана keystore из EAS (`Build Credentials z-YkrXj6T2`). При публикации:
- либо включите **App Signing by RuStore** и подпишите той же связкой,
- либо следите, чтобы все будущие сборки использовали **один и тот же keystore** (иначе обновления не встанут).

### 8. Приём денег (для выплат RuStore Pay)
RuStore Pay выплачивает на российский счёт. Понадобится статус **ИП (УСН 6%)** или юрлицо (самозанятость часто не подходит для продажи приложений). Уточните требования в Console → Монетизация.

## Порядок действий для первого запуска
1. Создать приложение в Console → получить Console App ID.
2. Вписать `consoleAppId` в app.json → пересобрать AAB.
3. Создать товар `voicetask_pro_unlock` (99 ₽).
4. Опубликовать политику, сделать скриншоты.
5. Загрузить AAB, заполнить карточку, отправить на модерацию.
