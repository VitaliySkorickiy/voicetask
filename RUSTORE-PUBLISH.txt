ШАГ 1. Сборка release
----------------------------------------
cd /d C:\голосовой_задачник\VoiceTask-ota-1.2.3
(скопировать App.js, app.json, eas.json, plugins, model-ru small)

npm install
npx expo config --type public
set EAS_NO_VCS=1

# AAB (предпочтительно для магазина)
eas build -p android --profile production

# или APK, если удобнее загружать APK
eas build -p android --profile production-apk

Дождись ссылки, скачай файл. Архив НЕ 1.5 GB.

ШАГ 3. Текст для магазина (можно копировать)
----------------------------------------
Краткое:
Голосовые заметки: скажи задачу — она в списке и на календаре. Офлайн.

Полное:
«Голосовые заметки» — быстрый захват дел голосом или текстом.

• Голосовой ввод (офлайн на поддерживаемых устройствах)
• Умный разбор: «завтра», «в пятницу», «пятое ноября»
• Календарь с метками по дням
• Приоритеты и категории
• Работает без интернета для списка задач

Бесплатно: до 3 активных задач и 3 голосовых вводов.
Pro (99 ₽ один раз): без лимитов, без подписки.

Ключевые слова:
голосовые заметки, голосовой планировщик, задачи голосом, to do голос, календарь задач

ШАГ 5. Оплата Pro (после первой публикации)
----------------------------------------
1) В Console: монетизация → разовой товар
   productId: voicetask_pro_unlock
   цена: 99 ₽
2) Подключить RuStore Pay SDK в следующей сборке
3) Кнопка «Купить Pro» → purchase() вместо Alert

Пока SDK нет — приложение уже можно продавать как Free + лимиты;
код активации только друзьям, не в карточке магазина.
