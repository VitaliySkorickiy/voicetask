# Публикация «Голосовые заметки» в RuStore — полная инструкция (для первого раза)

> Весь процесс делится на 3 больших этапа:
> 1. Юридический статус (чтобы можно было получать деньги).
> 2. Кабинет RuStore (Console): создать приложение и товар.
> 3. Загрузить сборку, заполнить карточку, пройти модерацию.
>
> Часть шагов делаю я (код/сборка), часть — вы (аккаунт, документы, скриншоты).

---

## ЧАСТЬ 1. Юридический статус (нужен для денег)

RuStore — российский магазин, деньги от продаж платятся на российский банковский счёт.

- **Бесплатное приложение** можно опубликовать и как физлицо.
- **Встроенные покупки (RuStore Pay, ваш Pro за 99 ₽)** — обычно требуется статус **ИП** или **юрлицо**. Самозанятость (НПД) чаще всего не подходит для продажи приложений через магазин.

Что делать, если вы ещё без ИП:
1. Оформить **ИП** (через Госуслуги или банк — Тинькофф/Точка/Сбер дают это бесплатно, ~1 день).
2. Режим налога — **УСН «доходы» 6%** (самое простое для торговли).
3. Открыть **расчётный счёт** (обычно в том же банке).

> Если не хотите открывать ИП прямо сейчас — опубликуйте сначала **бесплатную** версию без оплаты, а RuStore Pay подключите позже, когда будет ИП. Приложение при этом уже начнёт набирать установки и отзывы.

## ЧАСТЬ 2. Регистрация разработчика в RuStore Console

1. Откройте в браузере: **https://console.rustore.ru**
2. Войдите (обычно через **VK ID** или телефон).
3. Пройдите **регистрацию разработчика** — заполните данные (ФИО, для ИП/юрлица — реквизиты, ИНН).
4. Дождитесь подтверждения (обычно быстро, до 1 рабочего дня).

---

## ЧАСТЬ 3. Создать приложение и получить Console App ID

1. В Console нажмите **«Приложения»** → **«Создать приложение»**.
2. Заполните:
   - **Название:** Голосовые заметки
   - **Пакет (applicationId):** `ru.vitaliyskorickiy.voicetask` (ровно так, без ошибок — это важно!)
3. Нажмите «Создать».

4. Теперь откройте созданное приложение. В адресной строке браузера будет URL вида:
   ```
   https://console.rustore.ru/apps/123456/versions
   ```
   Число **`123456`** — это **Console App ID**.

> ⚠️ **Пришлите мне это число** (или впишите сами в `app.json` → `withRuStorePay` → `consoleAppId`). Без него оплата не заработает, и мне нужно пересобрать AAB с этим ID.

---

## ЧАСТЬ 4. Создать товар (встроенная покупка Pro)

1. В Console, внутри приложения: левое меню → **«Монетизация»** → **«Встроенные покупки»** → **«Создать товар»**.
2. Заполните:
   - **Тип:** Нерасходуемый товар (non-consumable) — покупается один раз навсегда.
   - **Идентификатор:** `voicetask_pro_unlock` (ровно так — он зашит в коде).
   - **Название:** Pro — без ограничений.
   - **Цена:** 99 ₽.
3. Сохраните. Товар станет активным после публикации приложения.

## ЧАСТЬ 5. Политика конфиденциальности (нужна публичная ссылка)

RuStore требует ссылку на политику конфиденциальности. Текст уже готов в файле `PRIVACY_POLICY.md`.

Как получить ссылку (бесплатно, 2 минуты):
1. Откройте **https://telegra.ph** (сервис от Telegram, регистрация не нужна).
2. Вставьте туда текст из `PRIVACY_POLICY.md` (заголовок — «Политика конфиденциальности — Голосовые заметки»).
3. Нажмите **Publish**.
4. Скопируйте ссылку вида `https://telegra.ph/...` — это и будет ваша политика.

> Альтернатива: GitHub Pages, любой бесплатный хостинг, Google Docs (опубликовать в интернет).

## ЧАСТЬ 6. Скриншоты (минимум 3–4)

Сделайте скриншоты на телефоне (или эмуляторе) прямо в приложении:

1. Главный экран со списком задач.
2. Экран «Новая задача» (голосовой ввод, микрофон).
3. Вкладка «Календарь» с точками-задачами.
4. Экран Pro (кнопка «Купить Pro · 99 ₽»).

Требования: по ширине ~1080 px, без чужих логотипов и без кода `DRUZIA2026` в кадре.

## ЧАСТЬ 8. Загрузка сборки и заполнение карточки

1. В Console, внутри приложения: **«Версии»** (или «Черновики») → **«Загрузить версию»**.
2. Загрузите **AAB** файл, который я соберу.
3. Дождитесь обработки файла (несколько минут).

Затем заполните карточку приложения (обычно на вкладке «Описание» или «Карточка»):
- **Название:** Голосовые заметки: задачи голосом
- **Короткое описание:** из `RUSTORE-ASO.md`
- **Полное описание:** из `RUSTORE-ASO.md`
- **Категория:** Продуктивность / Инструменты
- **Возрастной рейтинг:** 0+ (для всех)
- **Скриншоты:** 4 штуки (Часть 6)
- **Иконка:** `assets/icon.png` (уже есть)
- **Политика конфиденциальности:** ссылка из Части 5
- **Цена приложения:** бесплатно (Pro — это встроенная покупка, а не цена приложения)

## ЧАСТЬ 9. Подпись приложения (важно!)

Ваше приложение подписывается ключом через EAS (он уже настроен, ключ один и тот же для всех сборок).

При загрузке AAB RuStore может предложить вариант подписи. Действуйте так:
- Если предлагают **«App Signing» (подпись силами RuStore)** — соглашайтесь, это проще: RuStore сам подпишет приложение и будет подписывать будущие обновления.
- Если просят загрузить свой ключ — скажите мне, я помогу выгрузить keystore из EAS.

> Главное правило: **все обновления должны подписываться одним и тем же ключом**, иначе обновление не встанет поверх старого.

## ЧАСТЬ 10. Модерация и запуск

1. Нажмите **«Отправить на модерацию»**.
2. Модерация RuStore обычно занимает **1–5 рабочих дней** (иногда дольше).
3. Если пришлют замечания — исправьте и отправьте снова (могу помочь с текстом/карточкой).

После одобрения приложение появится в RuStore.

3. Комиссию RuStore уточните в Console (ориентировочно ~10–15%).
