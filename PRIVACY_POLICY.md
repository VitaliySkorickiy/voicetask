# Политика конфиденциальности — «Голосовые заметки»

**Последнее обновление:** 5 ноября 2026 г.

Приложение «Голосовые заметки» (далее — Приложение) разработано с приоритетом конфиденциальности. Ниже описано, какие данные обрабатываются и как они используются.

## 1. Какие данные обрабатывает Приложение

- **Задачи (текст и распознанная речь).** Всё, что вы вводите текстом или голосом, хранится **только на вашем устройстве** (локальное хранилище). Данные не передаются на серверы разработчика.
- **Микрофон (аудио).** Используется только в момент голосового ввода для распознавания речи. Распознавание выполняется **офлайн на устройстве** (встроенная модель Vosk); аудио не записывается в файл и никуда не отправляется.
- **Покупки.** Оплата функции Pro обрабатывается платёжной системой **RuStore Pay**. Приложение не получает и не хранит данные банковских карт — платёжные данные обрабатываются RuStore.

## 2. Разрешения

Приложение запрашивает следующие разрешения только для описанных функций:

- **Микрофон** — для голосового ввода задач.
- **Уведомления** — для напоминаний о задачах.
- **Точные будильники** — для напоминаний по расписанию.
- **Вибрация** — для уведомлений.

## 3. Передача данных третьим лицам

Приложение **не передаёт** ваши задачи или аудио третьим лицам. Единственное взаимодействие с третьей стороной — платёжная система RuStore Pay при добровольной покупке Pro.

## 4. Хранение и удаление данных

Все данные хранятся локально на устройстве. При удалении Приложения все данные удаляются вместе с ним.
