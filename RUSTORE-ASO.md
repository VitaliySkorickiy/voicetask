# ASO для RuStore — «Голосовые заметки»

## Название приложения
**Голосовые заметки: задачи голосом**

## Короткое описание (до 80 символов)
Задачи голосом и текстом с умными датами и календарём. Работает офлайн.

## Полное описание
«Голосовые заметки» — быстрый захват дел голосом или текстом.

• Голосовой ввод с распознаванием **офлайн** (работает без интернета и без Google-сервисов)
• Умный разбор: «завтра», «в пятницу», «пятое ноября» — дата подставится сама
• Календарь с метками по дням
• Приоритеты и категории
• Список задач работает полностью офлайн

Бесплатно: до 3 активных задач и 3 голосовых ввода.
Pro (99 ₽, разово): без ограничений, без подписки.
