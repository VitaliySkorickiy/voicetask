ОБЯЗАТЕЛЬНЫЕ ФАЙЛЫ ИКОНОК
========================

Положите сюда следующие файлы (иначе EAS-сборка упадёт):

1. icon.png
   - Размер: 1024 × 1024 px
   - Формат: PNG
   - Без прозрачности (сплошной фон)
   - Квадрат, логотип по центру

2. adaptive-icon.png
   - Размер: 1024 × 1024 px
   - Формат: PNG с прозрачностью
   - Только логотип (foreground)
   - Safe zone: центральные 66% (около 672×672)

3. splash-icon.png
   - Размер: 1024 × 1024 или 512 × 512
   - Формат: PNG
   - Логотип на прозрачном фоне

4. notification-icon.png (опционально)
   - Размер: 96 × 96
   - Белый силуэт на прозрачном фоне

Цвета бренда:
- Primary: #4F46E5 (Indigo)
- Background splash: #4F46E5

После добавления файлов можно собирать:
npx eas build --profile preview --platform android
